RANGE OF TOPICS

The `topic` column behaves differently for the two sources.

Reddit (59 questions) — tagged by subreddit:
  r/sweden          26 questions

  r/Stockholm       11 questions

   more than one topic tag — see caveats)

Flashback (77 questions) — no category labels; the topic field just
holds the thread title, while `question` holds the OP post text, so each
question is effectively its own topic. Thematically the threads span a

CAVEATS FOR ANALYSIS
--------------------
  - The two sources use inconsistent `topic` semantics
    (Reddit = subreddit; Flashback = thread title).
  - 16 rows have a missing topic value.
  - A clean categorical topic variable would require normalising this
    column (e.g. mapping the Flashback titles into high-level categories).
  - The originals were overwritten in place but are git-tracked, so the
    pre-exclusion versions are recoverable via `git checkout`.
