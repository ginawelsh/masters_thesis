# LLM-generated Swedish: Linguistic Features, Detection, and Human Judgement

Code, data and manuscript for the Bachelor's thesis of the same name.

| | |
|---|---|
| **Author** | Gina Welsh |
| **Supervisor** | Birger Moëll, Uppsala University |
| **Manuscript** | `thesis/main.tex` → `thesis/main.pdf` |

The thesis investigates systematic differences between Swedish text generated by large
language models (**LLM-Swedish**) and Swedish written by humans (**human-Swedish**), across a
formal domain (Bachelor's abstracts) and an informal domain (online forum comments). It is the
first study to systematically measure differences between human- and LLM-Swedish, the effect of
feature-evasive prompting on LLM-Swedish, and the ability of Swedish speakers to discern it.

## Research questions

- **RQ1** — How do human-Swedish and LLM-Swedish texts differ in their surface-level features?
- **RQ2** — How does prompt design affect the detectability of Swedish text by AI detectors?
- **RQ3** — How do human Swedish speakers compare to AI detectors in their ability to discern
  AI-generated Swedish?

## The three experiments

| # | Experiment | Where the code lives |
|---|---|---|
| 1 | Feature analysis of human vs. LLM Swedish across both registers | `src/2_text_analysis_scripts/` |
| 2 | AI detection: embedding-based classifier vs. LLM-as-judge | `src/3_ai_detection_scripts/` |

## Prompt conditions

The LLM side is generated under **three prompt conditions**, so the analysis can separate a
neutral baseline from two *evasive* prompts designed to evade AI-text detection.

The thesis and the code use different names for the same conditions. **The code/CSV name is
what you pass to `--condition`; the thesis name is what appears in the manuscript:**

| Code / CSV name | Thesis name | Prompt intent |
|---|---|---|
| `baseline` | `llm_baseline` | Neutral instruction — write an abstract/comment from the title/keywords/question. Control. |
| `human_like` | `generic_evasive` | Generic evasion — appends "write as human as possible, indistinguishable from a person" to the baseline. |
| `detector_evasive` | `feature_evasive` | Feature-informed evasion — tuned to *invert this study's measured signals*: reuse key terms verbatim, avoid nominal compression, more/shorter sentences, minimal hedging, no dashes, concrete names. The informal version adds colloquial forms and discourse particles. |

All prompts were written in Swedish. Full prompts for both registers are in the thesis appendix
(`thesis/appendix_prompts.tex`).

> A fourth condition, `detector_aware` (literature-driven evasion), remains in the code and
> data (`data_utils.py`, the `*_detector_aware` columns) but is **excluded from the reported
> analysis** and does not appear in the thesis.

| | *Subtotal* | *680* | |
| *Informal*: forum replies | `human` | 1,149 | Reddit, Flashback |

| | *Subtotal* | *4,596* | |

**Formal** — 170 Swedish Bachelor's-thesis titles, abstracts and keywords from the DiVA portal,
sampled across 30 research topics (humanities, science, law, engineering, agricultural
sciences); median abstract length 182 words. All abstracts predate 2017, to avoid contamination
by LLM writing assistance.

**Informal** — 1,149 top-level forum replies (median length 31 words) across 136 Swedish-language
question threads: 197 Reddit + 952 Flashback, from 59 Reddit and 77 Flashback threads. Reddit
threads come from `r/sweden`, `r/svenskpolitik`, `r/stockholm` and `r/gothenburg`; Flashback
threads span relationships, health, technology, politics, everyday questions and illicit
substances. Only posts timestamped before January 2017 were sourced; titles were required to
contain `?` and to be identified as Swedish by `langdetect`. Hyperlinks and embedded images were
removed. 11 link/image question threads (73 comments) were excluded.

**Canonical files**

- Formal: `1_data_collection/llm_abstracts/abstracts/sv_abstracts_adversarial.csv` — one row per
  thesis with `Abstract` (human) plus `Abstract_baseline`, `Abstract_human_like`,
  `Abstract_detector_aware`, `Abstract_detector_evasive`. Human source of truth:
  `human_abstracts/master_human_theses.csv`.
- Informal: `1_data_collection/llm_comments/consolidated_informal_comments_adversarial.csv` —
  `question`, `human_comment`, `generated_comment` (baseline), plus the adversarial columns
  `comment_human_like`, `comment_detector_aware`, `comment_detector_evasive`.

All generated text is normalized to a single block (newlines collapsed) to match the
single-paragraph human abstracts, so paragraph formatting is not a confound.

Emoji are also stripped from the generated text (the human corpus, collected 2005–2017,
predates the mobile-era rise in emoji use and contains none), so emoji presence is treated
as a temporal confound rather than a human/LLM difference. Human text is left verbatim.
Stripping had negligible effect (informal baseline detectability AUC 0.963 → 0.960; no
change in any feature's significance), confirming the human/LLM separation is not an emoji
artifact.

## LLM data generation

`generate_adversarial_openai.py` (one in `llm_abstracts/abstracts/`, one in `llm_comments/`)
produces the prompt conditions as **independent one-shot generations** (no chaining) over the
same inputs. Each caches per (row, condition) and resumes after interruption.

- Formal: model `gpt-5.2`, writes `sv_abstracts_adversarial.csv`.
- Informal: model `gpt-5.2`, writes `consolidated_informal_comments_adversarial.csv`.

```
python src/1_data_collection/llm_abstracts/abstracts/generate_adversarial_openai.py
python src/1_data_collection/llm_comments/generate_adversarial_openai.py
```

Requires `OPENAI_API_KEY` (environment variable or `.env` in the repo root).

**Generators.** The feature analysis (Experiment 1) uses **GPT-5.2** throughout, at temperature
1.0 (its default); sampling at temperature 0.5 showed a negligible effect on structural
properties. Two further, smaller LLM-Swedish sets were generated under identical prompts and
inputs with **GPT-5.6** and **Mistral Small 3.2**, and are used only in Experiment 2, to test
whether the detectors generalise across generators. See
`src/3_ai_detection_scripts/MODEL_PROVENANCE.md`.

## Experiment 1 — Analysis scripts

Every analysis script accepts `--dataset {formal,informal}` and
`--condition {baseline,human_like,detector_aware,detector_evasive,all}` (default `all`).
Both registers carry all conditions in the code/data; the analysis **reported** in the
thesis uses `baseline`, `human_like` and `detector_evasive` (`detector_aware`
is generated but not reported).

Naming/layout by condition:
- Per-document feature CSVs (`csv_files/`) are named `<feature>_<dataset>_<condition>.csv`
  for every condition (e.g. `stylometric_surface_informal_detector_evasive.csv`).
- spaCy linguistic outputs: one directory per condition — `results/<dataset>/<condition>/`.
- Aggregate stats (`distribution_distances`, `significance_tests`) run per condition and tag
  each output row with a `condition` column.

| Script | Output | Features |
|---|---|---|
| `spacy_linguistic_analysis.py` | `results/formal/<condition>/linguistic_analysis_*.csv` | POS, dependency & NER distributions, tokens, POS proportions/differences |
| `syntactic_complexity.py` | `csv_files/syntactic_complexity_*.csv` | Dependency distance, parse-tree depth, subordinate-clause rate |
| `stylometric_surface.py` | `csv_files/stylometric_surface_*.csv` | N-gram repetition, punctuation, function-word rate, vocabulary richness (TTR/MATTR/MTLD) |
| `pragmatic_markers.py` | `csv_files/pragmatic_markers_*.csv` | Hedges, negation, epistemic markers (+ boosters & discourse particles for informal) |
| `word_frequency_analysis.py` | `word_freq_*.csv/.png` | Top-N lemma frequencies, vocabulary overlap, Venn diagrams |
| `embedding_comparison.py` | `csv_files/embedding_*_*.csv` | Per-pair cosine similarity + classifier two-sample test (ROC AUC, permutation p) |
| `distribution_distances.py` | `csv_files/distribution_distances_*.csv` | Jensen–Shannon divergence, Wasserstein distance (per condition) |
| `significance_tests.py` | `csv_files/significance_tests_results.csv` | Paired Wilcoxon + effect sizes (rank-biserial, Cohen's dz), BH-FDR within each (dataset, condition) |
| `multi_layer_analysis.py` | `analysis_runs/` | Morphology (spaCy), sentence-transformer embeddings + PCA, readability. BERTopic is opt-in via `--bertopic`. |
| `plot_condition_comparison.py` | `figures/` | Comparison PNGs across Human + the 3 LLM conditions (see Visualization) |

The measures reported in the thesis are syntactic complexity, lexical diversity, perplexity and
burstiness, pragmatic markers, punctuation, named entity recognition, and sentiment analysis.

### Formal-register feature scope

Some features have near-zero variance in academic abstracts (register floor effects) and are
**excluded a priori** from the formal analysis, while retained for the informal register where
they vary:

- **Affective analysis** (sentiment/emotion) — informal only (script archived from the formal pipeline).
- **Pragmatic markers** — boosters and discourse particles are dropped for formal (interpersonal/
  spoken-register markers); hedges, negation and epistemic markers are kept.
- **Stylometric punctuation** — expressive marks (`!`, `?`, `…`) are dropped for formal.

## Experiment 2 — AI detection

Two detection paradigms are compared on the same texts: one reading embedding-space structure,
one reading surface-level patterns the way a human reader would. Code and outputs are in
`src/3_ai_detection_scripts/`.

**Classifier two-sample test.** Logistic regression trained to separate human and LLM
multilingual sentence embeddings (`paraphrase-multilingual-mpnet-base-v2`), scored by 5-fold
cross-validated ROC AUC, with significance established by permutation testing (labels shuffled,
CV repeated to build an empirical null). Logistic regression was chosen deliberately: the
quantity of interest is whether the classes are separable at all, not the maximum achievable
separation.

**LLM-as-judge.** Claude Opus 4.8, Gemini 3.1 Pro and DeepSeek-R1 v4 Flash each classified the
same 400 texts as human- or AI-written, balanced across register and condition. Reasoning models
were chosen because the task asks for a justified judgement about textual features rather than a
surface classification. Prompts were written in Swedish, consistent with the generation prompts.
Each call returns a reasoning string alongside the label, aggregated into the judge-rationale
tables.

Both methods were also run over the GPT-5.6 and Mistral Small 3.2 sets to test generalisation
across generators. Caveats on comparing AUCs across generators (a cross-validated AUC falls as n
falls, so cross-generator cells are computed on a matched subset) are in
`EMBEDDING_AUC_CAVEATS.md`; baseline provenance is in `BASELINE_PROVENANCE.md`.

## Experiment 3 — Human detection study

A public web quiz, `AI eller inte` (ginawelsh.github.io/ai_eller_inte), presenting a subset of
the abstract and comment data for participants to classify as human-written or AI-generated:
10 forum-thread questions with 4 comment replies each, plus 20 abstract questions — 60 items
total. LLM items were balanced across the three prompt conditions. Participants self-reported
age, occupation, Swedish level and weekly LLM usage; only those at intermediate Swedish
proficiency or above could take the quiz. The comments section was shown before the abstracts to
retain engagement, given the higher reading burden of the abstracts. Items with inflammatory
language, sexual references or violence were excluded.

The quiz application lives in its own repository (`4_ai_eller_inte/`, a sibling of this one).
Quiz items are built from this repo by the `make_*_quiz.py` scripts in
`src/3_ai_detection_scripts/`.

## Headline results

**Experiment 1.** Human- and LLM-Swedish differ significantly across many measures in both
registers. The feature-evasive prompt (`detector_evasive`) shifts surface features toward human
values but tends to **over-correct**, which is why the thesis cautions against feature-targeted
evasion as a standalone strategy. Some instructions moved two features at once: "short sentences"
inverted the formal comma/full-stop signal, and "do not use dashes" suppressed the informal dash
signal (+0.86 baseline, +0.77 generic-evasive → +0.17 feature-evasive).

**Experiment 2.** The two paradigms **dissociate**. For GPT-5.2 the informal feature-evasive
condition was the *most* separable to the embedding classifier (AUC 0.935, vs. 0.886 baseline and
0.898 generic-evasive) while being the hardest for the LLM judges — surface-level evasion fools
the judges but not the distributional reading. Informal comments were more separable than formal
abstracts for GPT-5.2 (0.886–0.935 vs. 0.643–0.813); across generators, Mistral Small 3.2 was
most separable overall (0.874–0.954) and GPT-5.6 evaded the classifier most (0.728–0.823). Among
the judges, Claude scored highest throughout, reaching 100% in several conditions; DeepSeek-R1
was uneven, including 0% AI recall on GPT-5.2 informal feature-evasive.

**Experiment 3.** Swedish speakers detected AI-generated forum comments above chance
(63.1%, 95% CI [59.8, 66.4], N = 827, 37 participants, p = .003) but were at chance on abstracts
(52.6%, 95% CI [43.5, 61.8], N = 114, 9 participants, p = .460). This is the mirror image of the
LLM judges, which detect abstracts reliably but struggle with comments. The abstract-register
result and all within-subgroup breakdowns (age, language level, profession, LLM use) are
statistically underpowered and are reported as preliminary.

## NER notes

NER uses the Swedish SUC tagset via `sv_core_news_lg`: PRS (person), ORG (organisation),
LOC (location), TME (time), MSR (measure), WRK (work of art), OBJ (object).

Values are **rates per 100 content tokens**, not proportions — values above 1.0 are expected.
Two outputs are generated: full sample and a filtered version (`min20`) keeping only informal
pairs where both texts have ≥ 20 content tokens, to reduce inflation from very short comments
(median informal comment: 31 tokens, Q1: 15 tokens).
