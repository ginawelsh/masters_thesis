===============================================================================
CLUU THESIS — RESULTS COMPILATION (for the paper)
===============================================================================
Generators: OpenAI GPT-5.2 (primary, §1–3) + Mistral-Small-3.2 (model comparison, §4).
Corpus (post-exclusion, matched pairs):
  Formal (thesis abstracts):  n = 170 pairs
  Informal (forum comments):  n = 1,149 pairs
Reported prompt conditions: baseline, human_like, detector_evasive.
  (detector_aware is generated but excluded from the reported analysis and is
   not shown.)

FRESHNESS NOTE
  - Embedding detectability and the paired Wilcoxon feature tests below are on
    the current post-exclusion corpus (n = 170 / 1,149) and are citable.
  - Fresh informal sentiment/affect IS reported in §4d (model-comparison run,
    n = 1,149, emoji-free). The OLD main-pipeline sentiment distribution CSVs
    (inf_sentiment_distribution.csv, n = 204) remain stale; formal sentiment is
    excluded by design.
  - NER distribution means are reported with the direction corroborated by the
    fresh per-document significance run.

Effect-size convention: Cohen's dz sign is (LLM − human).
  +dz  => LLM > human ;  −dz => human > LLM.  All listed features are
  significant at Benjamini–Hochberg FDR q < 0.05 (paired Wilcoxon signed-rank).


===============================================================================
1. EMBEDDING DETECTABILITY (classifier two-sample test)
===============================================================================
Method: logistic regression on multilingual sentence embeddings
(paraphrase-multilingual-mpnet-base-v2), 5-fold stratified CV, 1000 label
permutations. ROC AUC 0.5 = indistinguishable, 1.0 = perfectly separable.
Mean pair cosine = similarity between each human doc and its own LLM
regeneration. Permutation p = 1/1001 in every run (report as p < 0.001);
null mean AUC ≈ 0.50 throughout.

FORMAL (n = 170 / class)
  Condition          CV ROC AUC   Mean cos   Median cos
  baseline              0.754       0.775       0.804
  human_like            0.764       0.760       0.800
  detector_evasive      0.880       0.749       0.778

INFORMAL (n = 1,149 / class)
  Condition          CV ROC AUC   Mean cos   Median cos
  baseline              0.960       0.470       0.483
  human_like            0.963       0.479       0.498
  detector_evasive      0.981       0.480       0.500

Key points:
  - Informal text is far more separable than formal (AUC ≈ 0.96–0.98 vs
    0.75–0.88).
  - Adversarial evasion prompts INCREASE embedding-level detectability rather
    than reducing it (AUC rises under detector_evasive).

===============================================================================
CROSS-CUTTING TAKEAWAYS
===============================================================================
1. LLM Swedish is separable from human Swedish in every condition and both
   registers (embedding p < 0.001; dozens of features significant at FDR).
2. Register matters: informal comments are far more detectable than formal
   abstracts, at both the embedding and feature level.
3. Direction of the lexical-diversity signal flips by register (LLM > human in
   formal abstracts; human > LLM in informal comments).
4. Adversarial evasion inverts hand-crafted SURFACE features (clearly in the
   formal register) but does NOT reduce — and actually increases —
   embedding-level separability. Surface-feature evasion != semantic evasion.
5. Model identity matters: Mistral-Small-3.2 is substantially more human-like
   than GPT-5.2 in the FORMAL register (median |dz| ~0.30 vs ~0.48), though both
   share the same directional tells. The GPT baseline positivity bias is
   model-specific — Mistral shows none and tracks human sentiment. (§4)
